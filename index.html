Neon Serverless PostgreSQL (Nuvem 100% Gratuita)

O Neon é um banco de dados PostgreSQL Serverless em nuvem com plano gratuito vitalício (0.5 GiB de armazenamento, suspensão automática e branching instantâneo). Não expõe credenciais e funciona perfeitamente com a hospedagem gratuita da Vercel.

Como Configurar sua Infraestrutura 100% Gratuita (Guia Passo a Passo)

1 Neon PostgreSQL

Acesse console.neon.tech, crie uma conta gratuita com GitHub e crie um projeto.

Copie a string Connection string (com psql ou Node.js) e cole no campo acima.

2 GitHub Repositório

Crie seu repositório gratuito no github.com (público ou privado).

Faça o git push do seu código. O versionamento seguro manterá seu histórico protegido.

3 Vercel Deploy

No vercel.com, importe seu repositório GitHub (Hobby Plan 100% Free).

Adicione as variáveis de ambiente VITE_NEON_DATABASE_URL e VITE_GEMINI_API_KEY.
